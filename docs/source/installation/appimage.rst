=========================
Installation via AppImage
=========================

We provide prebuilt AppImages on `GitHub <https://github.com/kryptoloesungen/CiVerLy/releases/latest/>`_.
AppImages require Linux.
Download the image and make it executable:

.. code-block:: console

   $ wget https://github.com/kryptoloesungen/CiVerLy/releases/latest/download/civerly.AppImage
   $ chmod +x civerly.AppImage

Then, simply excecute the AppImage

.. code-block:: console

   $ ./civerly.AppImage

This will drop you into a sage shell with CiVerLy and it dependencies available.
Alternatively, you can enter a normal shell by running:

.. code-block:: console

   $ ./civerly.AppImage --sh
